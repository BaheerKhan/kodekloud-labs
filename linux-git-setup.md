**Platform:**  
KodeKloud Engineer Practice Labs

## Objective
Install Git on the Storage Server and create a bare repository for collaborative application development.

---

## Requirements
- Install Git using the `yum` package manager
- Create a bare Git repository at `/opt/games.git`

---

## Steps Performed
- Logged in to the Storage Server
- Installed Git using the `yum` package manager
- Verified the Git installation
- Created a bare Git repository at `/opt/games.git`
- Verified the repository structure and permissions

---

## Outcome
Git was successfully installed, and the bare repository `/opt/games.git` was created and is ready for collaborative development.

## Key Learnings
- Installing and verifying Git on Linux systems
