# Temporary User – yousuf
**Platform:**  
KodeKloud Engineer Practice Labs

---

## Objective
Create a temporary user account `yousuf` on App Server 3 with a defined expiry date to support short-term project access.

---

## Requirements
- Username: `yousuf` (lowercase)
- Server: App Server 3 (Stratos Datacenter)
- Account expiry date: `2024-02-17`

---

## Steps Performed
- Logged in to App Server 3 via SSH
- Created user `yousuf` with an account expiration date
- Verified the user account and expiry configuration

---

## Outcome
Temporary user `yousuf` was successfully created on App Server 3 with an expiry date set to **2024-02-17**, ensuring time-bound access.

---

## Key Learnings
- Creating temporary user accounts in Linux
- Setting account expiration dates using system tools
- Enforcing least-privilege and time-based access
- Managing short-term user access in enterprise environments
