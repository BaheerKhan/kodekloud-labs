# AWS Subnet – xfusion-subnet
**Platform:**  
KodeKloud Engineer Practice Labs

---

## Objective
Create a subnet named `xfusion-subnet` within the default VPC as part of an incremental AWS cloud migration.

---

## Requirements
- Cloud provider: AWS
- VPC: Default VPC
- Subnet name: `xfusion-subnet`
- Region: `us-east-1`

---

## Steps Performed
- Logged in to the AWS Management Console
- Navigated to the VPC service
- Identified the default VPC in the `us-east-1` region
- Created a new subnet named `xfusion-subnet`
- Associated the subnet with the default VPC
- Verified subnet creation and configuration

---

## Outcome
Subnet `xfusion-subnet` was successfully created within the default VPC and is ready for use in the AWS migration process.

---

## Key Learnings
- Understanding AWS VPC and subnet architecture
- Creating and managing subnets in AWS
- Working with default VPC resources
- Preparing network components for cloud migration
