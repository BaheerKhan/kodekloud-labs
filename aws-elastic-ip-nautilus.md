# AWS Elastic IP Allocation – nautilus-eip

**Platform:**  
KodeKloud Engineer Practice Labs

---

## Objective
Allocate a static Elastic IP address in AWS to support the Nautilus DevOps team’s incremental cloud migration strategy.

---

## Requirements
- Allocate an Elastic IP address
- Elastic IP name: `nautilus-eip`
- Use default AWS settings

---

## Steps Performed
- Logged into the AWS Management Console
- Navigated to the EC2 Elastic IPs section
- Allocated a new Elastic IP address
- Added a name tag `nautilus-eip`
- Verified the Elastic IP allocation

---

## Outcome
Elastic IP `nautilus-eip` was successfully allocated and is ready to be associated with AWS resources.

---

## Key Learnings
- Understanding Elastic IPs and their use cases
- Managing static public IP addresses in AWS
- Importance of tagging AWS resources
- Supporting incremental cloud migration efforts
