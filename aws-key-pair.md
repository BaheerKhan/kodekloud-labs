# AWS EC2 Key Pair – nautilus-kp

## Platform
KodeKloud Engineer Practice Labs

## Objective
Create an EC2 key pair in AWS to securely access instances as part of the Nautilus cloud migration.

## Requirements
- Key Pair Name: nautilus-kp
- Key Pair Type: RSA
- Region: us-east-1

## Steps Performed
- Logged into AWS Management Console
- Navigated to EC2 service
- Selected Key Pairs under Network & Security
- Created a new RSA key pair named `nautilus-kp`
- Verified successful key pair creation

## Outcome
RSA key pair `nautilus-kp` successfully created in us-east-1.

## Key Learnings
- Purpose of EC2 key pairs
- Difference between RSA and ED25519
- Secure access to EC2 instances
